# OSSysLink
UAE ossyslink.library an attempt at making a library that can interface with it's host system, exposing desired functionality.

Added: Amiga Folder
it contains C & E code for Opening ossyslink.library, while eventually I'll work on the C code stuff it's not the primary language of focus which is AmigaE (EVO) in this case, thus my lack of narration about it.
- Amiga/E
Build              - amiga script for building the code.
ossyslink.m        - pre-compiled module.
pragma_ossyslink.h - so pragma2module can convert it to the forementioned module.
test_ossyslink     - Amiga executable binary
test_ossyslink.e   - AmigaE code for the forementioned executable
